Day 1 - Version Control Fundamentals

Version control records changes made to files over time.

Git is a distributed version control system.

GitHub is an online platform that hosts Git repositories.

Git can work locally without GitHub.

A repository is a project managed by Git.

A commit is a saved snapshot of a project.

A branch is an independent line of development.

A remote is another copy of a Git repository.

Push sends commits to a remote repository.

Pull downloads and integrates remote changes.

Clone downloads a complete Git repository.
