# Important commands

git status
git diff
git add filename
git diff --staged
git commit -m "Message"
git log --oneline
git push


# Git workflow

Edit a file
    ↓
Working directory

git add
    ↓
Staging area

git commit
    ↓
Local repository

git push
    ↓
Remote repository


# The main concept is:

Working directory
    |
    | git add
    ↓
Staging area
    |
    | git commit
    ↓
Local repository
    |
    | git push
    ↓
GitHub
