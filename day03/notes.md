# Day 3 - Command-Line Basics

## Commands learned

- `cd` changes the current directory.
- `dir` lists files and folders in Command Prompt.
- `ls` lists files and folders in Git Bash.
- `mkdir` creates a directory.
- `echo` writes text.
- `type` displays file content in Command Prompt.
- `cat` displays file content in Git Bash.
- `copy` copies a file.
- `move` moves a file.
- `ren` renames a file.
- `del` deletes a file.
- `rmdir` removes a directory.
- `cls` clears Command Prompt.
- `pwd` shows the current location in Git Bash.
- `.` means the current directory.
- `..` means the parent directory.
